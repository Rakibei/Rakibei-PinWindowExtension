# Rakibei-PinWindowExtension

A small mod that expands the pinned resource system to support multiple building upgrades and research upgrades at the same time.

## Features

* Pin up to 3 upgrades at once.
* Supports both:
  * Building upgrades.
  * Research upgrades.
* Building and research pins share the same 3 available slots.
* Pinning a 4th upgrade automatically removes the oldest pinned upgrade.
* Re-pinning an already pinned upgrade moves it to the newest slot.
* Each pinned upgrade has its own:
  * Resource requirements.
  * Close button.
  * Go To button.
* Building pins are automatically removed when the building is upgraded.
* Research pins are automatically removed when the research is purchased.
* Research pins use the same pin button style as the existing building upgrade UI.
* Pinned panels are spaced apart so multiple tracked upgrades remain easy to read.

## Notes

This mod only changes the upgrade tracking system.

It does not modify upgrade costs, research costs, resource generation, upgrade requirements, or research requirements.
